# seraict
웹 화면을 볼때 중요하다고 생각되는 부분에 대해 다음에 볼때 확인할 수 있도록
밑줄과 하이라이트 그리고 주석을 다는 프로그램

설치하는 법
1. Github.com/gnos001/seraict의 branch의 파일을 다운로드
2. 원하는 위치에 복사
3. chrome 브라우저의 맞춤설정 및 제어 > 확장프로그램 > 확장프로그램 관리 > 압축해제된 프로그램 로드
4. 복사해둔 프로그램이 있는 폴더 설정

사용법
1. 원하는 사이트를 열고
2. 하이라이트 표시하거나 또는 밑줄을 긋고 부분을 마우스로 선택한 후
3. 확장 프로그램을 열어 원하는 버튼을 클릭한다.
4. 주석을 원하는 경우, 주석 버튼을 누른 후 원하는 위치에 마우스를 클릭하고 주석을 입력한다.
